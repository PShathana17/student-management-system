# Student Management System

A console-based Student Management System developed using Python and
Object-Oriented Programming.

## Features

- Add Student
- View Students
- Search Student
- Update Student
- Delete Student
- Calculate Student Result
- Find Topper
- Input Validation
- Save Student Data
- Load Previous Data using JSON

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON

## OOP Concepts Used

- Classes and Objects
- Constructor (`__init__`)
- Instance Variables
- Methods
- Encapsulation
- Object-based data management
